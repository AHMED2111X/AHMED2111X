# 🦅 FALCON INTEGRITY FIX v2.33

**Author:** ABUFARID  
**License:** Open Source  

إضافة متكاملة لنظام أندرويد مصممة لتجاوز فحوصات **Play Integrity API** وإخفاء آثار الروت وفتح البوت لودر بأعلى كفاءة، مع دعم كامل للبيئات الحديثة وتقنيات الإخفاء على مستوى النواة (Kernel-level).

---

## 📑 أبرز التحديثات والتعديلات في الإصدار v2.33

* **إضافة زر الأكشن (Action Button Support):** دمج سكريبت `action.sh` لتمكين التحديث الفوري لبصمة الجهاز إلى **Pixel 10** بنقرة واحدة من داخل مدير الروت (KernelSU / APatch / Magisk) ودون الحاجة لإعادة تشغيل الجهاز.
* **دعم شامل لـ SUSFS (جميع الإصدارات):** تهيئة وتفعيل خيارات الإخفاء الخاصة بـ **SUSFS / SUFS** وتعديل مسارات المونت (Mounts) والـ Kstat لمنع كشف الروت على مستوى النواة.
* **توافقية Zygisk Next 1.5.0+:** دمج طبقة توافقية مع الإصدارات الحديثة من Zygisk Next لمنع التعارضات وتثبيت استقرار النظام.
* **تزييف حالة البوت لودر (Bootloader Spoofing):** حقن الخصائص الموثوقة (`verifiedbootstate=green` و `flash.locked=1`) لإخفاء كشف البوت لودر المفتوح عن خدمات جوجل والمتجر.
* **نظام التحديث التلقائي:** ربط الإضافة بمستودع GitHub عبر `updateJson` لاستقبال التحديثات المستقبلية مباشرة داخل مدير الروت.

---

## 🛠️ التقنيات والبيئات المدعومة (Supported Features)

* **أنظمة الروت:** KernelSU / APatch / Magisk.
* **معدلات الإطارات:** تحسينات أداء نشطة لدعم وضع 165Hz / 165 FPS.
* **مستويات الإخفاء:** Kernel-level Hiding عبر SUSFS v1.5.0+.
* **البصمات الافتراضية:** Google Pixel 10 (Android 15/16).
* **تجاوز الفحوصات:** MEETS_DEVICE_INTEGRITY & MEETS_BASIC_INTEGRITY.

---

## 🚀 طريقة الاستخدام بعد التفليش

1. **تثبيت الإضافة:** قم بتفليش ملف `.zip` عبر KernelSU Manager أو APatch أو Magisk ثم أعد تشغيل الجهاز.
2. **تحديث البصمة عبر زر Action:**
   * افتح تطبيق الروت وانتقل إلى قسم **الإضافات (Modules)**.
   * اضغط على زر **Action** الخاص بإضافة **FALCON INTEGRITY FIX**.
   * سيتم تطبيق بصمة **Pixel 10** وإعادة تشغيل خدمات Google Play تلقائياً في الخلفية.
3. **مسح بيانات خدمات جوجل (مرة واحدة فقط):**
   * قم بمسح التخزين المؤقت والبيانات لكل من **Google Play Store** و **Google Play Services**.
   * افتح أي تطبيق لفحص الإنترجريتي لتأكيد نجاح التجاوز.
